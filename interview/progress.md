# Progress

State is set by one test: explain the topic out loud for 60 seconds, with no
notes. If it breaks, the state is not learned, whatever the dashboard says.

Set the first column on day one by running that test on all 16 topics. It takes
about 30 minutes and it is the answer to "I do not know what I do not know".
